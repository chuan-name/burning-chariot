# 燃烧战车 · Burning Chariot（网页复刻版）

新浪游戏大厅曾经代理运营的回合制战车对战游戏《燃烧战车》的浏览器复刻版。
调整**角度**与**力度**、算准**风力**，用会被炸烂的地形把对面从地图上抹掉。

单机部分仍是纯前端、零依赖、零构建：直接双击 `index.html` 就能玩。

```
open index.html          # macOS
```

## 操作

| 操作 | 说明 |
| --- | --- |
| `← →` | 移动战车（消耗燃料，爬坡更费油） |
| `↑ ↓` | 调整炮口角度（-25° ~ 90°） |
| `空格` | 按住蓄力，松开发射（蓄满约 2 秒，蓄力条上的白线是上一发用的力度） |
| `1 / 2 / 3` | 一号武器 / 二号武器 / 必杀 |
| 鼠标点道具 | 点一下选中，再点一下才用掉 |
| `Enter` | 跳过本回合（油不够时用来攒燃料） |
| `G` | 开关炮口指示线（只标角度，不预测落点） |
| `M` | 静音　·　`Esc` 暂停菜单 |

手机/平板会自动切到触屏按键。

## 规则

**燃料是唯一的资源。** 开炮和移动共用一条槽，上限 200，但开局只有 22 点——
勉强够打一发一号或二号武器再挪两步（奥丁的二号武器耗油 20，一发就见底）。
一号武器 6~14 点，二号武器贵一截，必杀要 108~132 点。每回合结束自动回十几点油，
省着用、打中敌人会多回一些，满地图乱跑会少回一些。攒一发必杀通常要六到八个回合。
油不够开炮时按 `Enter` 跳过，专心攒油。

**每一轮里每辆车都恰好出手一次**，延迟只决定这一轮内部的先后，不会让谁整轮没得打。
这一回合烧掉多少油，就换算成多长的延迟（`300 + 耗油 × 5.5`），延迟低的先动。
所以一号武器和二号武器的差别不只是威力，还有下一轮的位次；
也因此同一辆车最多连着出手两次——上一轮压轴，紧接着下一轮打头。

**很多信息故意不告诉你。** 界面上没有出手队列，不显示延迟，也不提示这一发会让出几手；
炮口指示线只标角度，不预测落点；轮到对手时，下方面板会退回显示你自己的车并置灰，
不会暴露对方的角度、力度、燃料和选中的武器；别人用道具时你只看得到「在用道具」，
看不到是哪一个。试射、看落点、照着蓄力条上的刻度微调、自己记账——这才是这类游戏的打法。

**地形会被炸烂。** 脚下被掏空就会掉落，落差超过 130px 要摔伤，掉出地图直接阵亡
（天空之城与浩瀚星空没有底）。45° 满力度的射程大致就是一整张地图的宽度，
奥丁最短、旋风最远，差距在 ±15% 以内。

**风**每回合变一点，正数往右吹。单回合变化不会太猛，越接近上下限回拉得越快，
所以极端风撑不过一两个回合。旋风的弹被吹得最厉害，兰登的能量弹几乎不受影响。

**必杀**没有单独的能量槽，它就是一发很贵的武器——攒够油按 `3` 释放，
代价是接下来被延迟压住好几手。

## 道具

每辆车最多带 4 个，赛前在「出战准备」里挑（暂时不限量），场上还能靠空投补
（每四回合投一次，开炮打中或开过去压到都能拿）。只能在**开炮之前**用，
一回合可以连用好几个——但「大回血 / 大回燃料」用完立刻交出回合，所以先用哪个本身就是一步棋。

| 道具 | 效果 |
| --- | --- |
| 双倍攻击 | 下一发**连打两枚**同样的炮弹（不是伤害 ×2，两发会互相改地形）。对必杀无效，只在本回合有效 |
| 加强攻击 | 三个回合内，下一发伤害 +50%，对必杀也算，可与双倍叠加（两发都 +50%） |
| 飞行 | 本回合改打定位炮，战车瞬移到落点。**不结束回合**，之后还能移动，但不能再开火 |
| 麻痹弹 | 本回合改打麻痹弹，命中的敌人三个回合不能移动（仍可用飞行，也会被地形推走） |
| 小回血 / 大回血 | 恢复 25% / 50% 耐久；大回血用完立刻结束回合 |
| 小回燃料 / 大回燃料 | 恢复 20% / 40% 燃料；大回燃料用完立刻结束回合 |
| 隐身 | 三个回合内敌人看不见你的车，只看得到炮弹轨迹和你挨打时的伤害数字；电脑也只能照你消失前的位置打 |

因为用了什么道具不会公开，藏牌是有价值的：先用加强攻击、跳过回合，
下一回合再用双倍攻击然后开炮——对手要等两发都 +50% 的炮弹落地，才明白发生了什么。

## 十辆战车

烈火（均衡）、红龙（强攻）、铁金刚（精准，耗油最省）、贝贝龙（连射）、
毒蜘蛛（毒伤、爬坡最强，三套武器耗油 8 / 11 / 115，对齐原版）、旋风（远程、受风最大）、
托尔（雷击、弹道在最高点分裂）、赤焰（灼烧）、兰登（直射、几乎无视风）、
奥丁（重装、血厚炮沉，挪一步都费油）。

差别落在三处：武器耗油（决定必杀多久放一次、每一手的延迟）、移动耗油（敢不敢换位）、
回油速度。三套武器共 30 种弹道行为——多发散射、顶点分裂、跳弹、穿地钻、落雷、
地毯覆盖、持续燃烧与中毒，详见游戏内「战车图鉴」。

## 五张战场

干枯之大地、深海遗迹（低重力）、天空之城（浮岛、掉下去即死）、浩瀚星空（低重力强风）、
熔岩峡谷（中间一道深谷）。每张图的重力、风力上限、地形生成规则都不同，还有随机昼夜。
低重力地图射程和别处一样，只是弹飞得更慢、滞空更久。

## 模式

单挑 1v1、组队 2v2（你 + 电脑队友 对 两台电脑）、同屏双人（两人共用一套键盘轮流出手），
以及局域网 1v1。
电脑分新兵 / 老手 / 王牌三档——难度只影响瞄准抖动和是否总选最优解，AI 不会作弊，
你隐身它就真的看不见。

## 局域网 1v1

Windows 开发版双击 `start-lan.bat`。脚本会安装一次轻量依赖、启动 HTTP/WebSocket 服务、
监听 `0.0.0.0:3000`、显示可用局域网 IPv4，并自动打开 `http://localhost:3000`。

免安装发行版位于 `release/Burning-Chariot/`：双击 `BurningChariot.exe` 即可。它已经内嵌
Windows x64 Node.js 运行时和 WebSocket 服务，旁边的 `game/` 是静态资源目录；分发时请把
整个 `Burning-Chariot` 文件夹一起复制，不要只复制 exe。

Windows 7 SP1 64 位兼容版位于 `release/Burning-Chariot-Win7-x64/`，双击
`BurningChariot-Win7.exe`。其服务器携带官方 Node 12.22.12 x64 兼容运行时，发布目录内的浏览器脚本
固定以 Google Chrome `102.0.5005.63`（`chrome102`）为构建目标。仍须连同旁边的 `game/`
`runtime/`、`server/` 目录整体分发。Windows 7 与 Node 12 均已停止官方安全维护，因此该版本只应在可信局域网内使用，
不要将 3000 端口映射或暴露到互联网。

房主在主菜单选择「局域网对战」并创建房间。另一台电脑连接同一 Wi-Fi/有线局域网，
在浏览器打开房主窗口中显示的 `http://192.168.x.x:3000`，然后输入 6 位房间号。

首次运行时 Windows Defender Firewall 可能询问是否允许访问：请选择允许「专用网络」。
不要为此关闭防火墙。若其他电脑打不开页面，请确认双方处于同一局域网且专用网络已放行。

单机不需要运行服务器；双击 `index.html` 时不会主动建立 WebSocket 连接。

### 开发与打包

```sh
npm install
npm test
npm run test:compat
npm run build:exe
npm run build:win7
```

EXE 使用当前 Node.js 官方 SEA（Single Executable Application）流程构建，服务端与 `ws`
先打成一个 CommonJS 入口，再注入 Windows x64 Node 运行时；网页静态资源保留为外置 `game/`
目录，以便稳定分发和检查。未签名的本地构建可能触发 Windows SmartScreen；正式发布可再用
代码签名证书签名，但这不影响局域网功能。

`build:win7` 下载并校验 Node.js 官方 `12.22.12` Windows x64 运行时；本地默认用 Windows
自带的 .NET 3.5 编译器生成轻量启动器，CI 则在该编译器缺失时使用同样兼容 Win7 的原生启动器。
浏览器脚本统一由 esbuild 转换到 `chrome102` 目标。现代版与 Win7 版使用不同发行目录，互不覆盖。

正式版本通过 GitHub Releases 发布：Windows 10/11 x64 下载
`Burning-Chariot-Windows-x64.zip`，Windows 7 SP1 x64 + Chrome 102 下载
`Burning-Chariot-Win7-x64-Chrome102.zip`。两个压缩包都必须完整解压后运行；发布流程详见
[`CI/CD 与发布说明`](.github/CI-CD.md)。
